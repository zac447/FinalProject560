# FinalProject560

The Tables.sql can be found either after you unzip the folder in the inital folder or if you go into the newnewFinalProject folder. For reference when when in the solution they can found in the SQL folder.



The Procedures.sql can also be found either after you unzip the folder in the intial folder or in the newnewFinalProject folder. Also in the SQL folder when the solution is open.



The data.sql can also be found either after you unzip the folder in the intial folder or in the newnewFinalProject folder. Also in the SQL folder when the solution is open.



The application code can be found in the following folders. The non sql realated classes can be found in the Data folder. Likewise if the solution is open it is the Data project. The DataDelegates and Models can be found in their respected folders in the Production folder. Also in the solution they can be found in the ProductionData project in their respected folders. All UI forms and code behinds can be found in the UserInterface2 folder. Likewise in the UserInterface2 project within the solution.



There is also a RebuildDatabase.ps1 script to rebuild the database in the solution items folder in the project solution.
